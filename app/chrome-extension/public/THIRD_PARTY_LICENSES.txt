webpage-mcp-connector. It provides complete upstream license terms and

The release contains ONNX Runtime Web 1.22.0 only:
  libs/ort.min.js
  workers/ort-wasm-simd-threaded.mjs
  workers/ort-wasm-simd-threaded.wasm

tokenizer Tensor compatibility shim; this is the prominent Apache-2.0
modification notice for that distributed derivative.
