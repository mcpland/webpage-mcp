# Webpage MCP Server Extension - Latest Release

## 🚀 Quick Installation

### 1. Download the Extension

Download [webpage-mcp-server-latest.zip](/releases/chrome-extension/latest/webpage-mcp-server-latest.zip)

### 2. Installation Steps

1. Extract the downloaded zip file
2. Open Chrome browser
3. Enter `chrome://extensions/` in the address bar
4. Enable "Developer mode" toggle in the top right corner
5. Click "Load unpacked"
6. Select the extracted folder

### 3. Verify Installation

- The extension icon should appear in the browser toolbar
- Click the icon to open the configuration panel
- Confirm the extension status is showing normal

## ⚙️ Configuration

### Native Server Connection

1. Make sure Native Server is running (default port 12306)
2. Enter the correct port number in the extension popup
3. Click the "Connect" button to test the connection

## 🔧 Troubleshooting

### Common Issues

1. **Extension fails to load**
   - Make sure Developer mode is enabled
   - Check if the folder structure is intact

2. **Cannot connect to Native Server**
   - Confirm Native Server is running
   - Check if the port number is correct
   - Check the browser console for error messages

3. **Functionality issues**
   - Refresh the page and try again
   - Restart the browser
   - Reload the extension

## 📞 Technical Support
